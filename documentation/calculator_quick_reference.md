# Calculator Quick Reference Guide

## Basic Operations
- **Addition**: Press the + button
- **Subtraction**: Press the - button
- **Multiplication**: Press the  button
- **Division**: Press the  button
- **Equals**: Press the = button

## Special Functions
- **Clear**: Press C to clear current entry
- **All Clear**: Press AC to reset calculator
- **Square Root**: Press  button
- **Square**: Press x button
- **Percentage**: Press % button
- **Negative/Positive**: Press +/- button

## Memory Operations
- **Memory Store (MS)**: Save displayed number
- **Memory Recall (MR)**: Show stored number
- **Memory Add (M+)**: Add displayed number to memory
- **Memory Clear (MC)**: Reset memory

## Themes
Toggle between Light, Dark, and Colorful modes using the Theme Selector.

## Tips
- For complex calculations, use parentheses to control order of operations
- Check the display regularly to ensure correct input
- Use the memory functions for multi-step calculations
