# Calculator User Guide

## Introduction

Welcome to the Calculator application! This guide will help you understand the features and functionality of our calculator application. The calculator offers a range of operations from basic arithmetic to advanced scientific calculations, all within a user-friendly interface.

## Getting Started

The calculator application features a clean, intuitive interface with:

- A numeric display that shows your inputs and calculation results
- Numeric keypad for entering numbers
- Operation buttons for performing calculations
- Theme selection for personalizing your calculator experience

## Basic Features

### Numeric Input

- Use the numeric buttons (0-9) to input numbers
- The decimal point button (.) allows you to enter decimal numbers
- Numbers will appear on the display as you type them

### Basic Operations

- Addition (+): Add two numbers together
- Subtraction (-): Subtract one number from another
- Multiplication (): Multiply two numbers
- Division (): Divide one number by another
- Equals (=): Calculate the result of your expression

### Clear Functions

- Clear (C): Clears the current entry
- All Clear (AC): Resets the calculator completely, clearing all previous inputs

## Advanced Features

### Scientific Operations

- Square Root (): Calculate the square root of a number
- Power (x): Calculate the square of a number
- Percentage (%): Convert a number to a percentage or calculate percentages
- Negative/Positive Toggle (+/-): Change a number from positive to negative or vice versa

### Memory Functions

- Memory Store (MS): Save the current number to memory
- Memory Recall (MR): Recall the number stored in memory
- Memory Add (M+): Add the current number to the value in memory
- Memory Clear (MC): Clear the stored memory value

## Special Features

### Theme Selection

The calculator offers multiple visual themes:
- Light Mode: Clean, bright interface suitable for daytime use
- Dark Mode: Reduced brightness theme, perfect for low-light environments
- Colorful Mode: Vibrant, customized color schemes

To change themes:
1. Look for the theme selector in the calculator interface
2. Click or tap on your preferred theme option
3. The calculator interface will update immediately

### Calculation History

View your recent calculations:
1. Look for the history button or panel
2. Access a list of your previous calculations
3. Click on any previous calculation to restore it to the main display

## Using the Calculator: Step-by-Step Examples

### Example 1: Basic Addition
1. Enter the first number (e.g., 5)
2. Press the addition (+) button
3. Enter the second number (e.g., 3)
4. Press equals (=)
5. The display will show the result: 8

### Example 2: Chaining Operations
1. Enter 10
2. Press multiply ()
3. Enter 2
4. Press equals (=) (display shows 20)
5. Press add (+)
6. Enter 5
7. Press equals (=)
8. The display will show 25

### Example 3: Using Memory Functions
1. Calculate a value (e.g., 42)
2. Press MS to store in memory
3. Perform other calculations
4. When needed, press MR to recall 42 back to the display

## Troubleshooting

### Common Issues

- **Display Shows Error**:
  - This typically occurs when attempting an invalid operation (like division by zero)
  - Press AC to clear the error and start again

- **Unexpected Results**:
  - Check the order of operations
  - Remember that the calculator follows mathematical precedence rules
  - Use parentheses when needed to group operations

- **Screen Unresponsive**:
  - Refresh the application
  - Check if your device meets the system requirements

### Tips for Accurate Calculations

- For complex expressions, break down your calculation into smaller steps
- Verify important calculations by performing them twice
- For very large or small numbers, be aware of potential precision limitations

## Keyboard Shortcuts

If you're using a physical keyboard with the calculator:
- Number keys (0-9) function as numeric input
- Operation keys (+, -, *, /) work for their respective operations
- Enter key works as equals (=)
- Escape key functions as All Clear (AC)
- Backspace removes the last digit entered

## System Requirements

- Modern web browser with JavaScript enabled
- Minimum screen resolution: 320x480 pixels
- Supported browsers: Chrome, Firefox, Safari, Edge (latest versions)

## Privacy Information

The calculator processes all calculations locally on your device. No calculation data is sent to external servers or stored permanently unless you explicitly use a save feature.
