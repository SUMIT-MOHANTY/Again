# CI/CD Scaffold\n\nThis repository includes Dockerfiles, a Docker‑Compose setup, and GitHub Actions workflows for CI and deployment.\n\n## Local Development\n1. Copy the example environment file: `cp .env.example .env` and adjust values as needed.\n2. Run `docker compose up --build` to start PostgreSQL, Redis, the FastAPI backend, and the React frontend.\n\nThe CI workflow runs on every push, while the Deploy workflow runs only on pushes to the `main` branch.\n
