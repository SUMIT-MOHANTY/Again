# Project README\n\n## Encryption at Rest\n\n- **Placeholder key** is provided via the `ENCRYPTION_KEY` environment variable. The default value is a base64‑encoded 32‑byte key suitable for development only.\n- Encryption logic lives in `backend/services/encryption.py` and uses **Fernet** (AES‑128‑GCM) for simplicity.\n- To rotate the key, update `ENCRYPTION_KEY` and run a one‑off migration that decrypts existing `encrypted_ssn` values and re‑encrypts them with the new key.\n- PostgreSQL column `encrypted_ssn` (BYTEA) stores the ciphertext. Plain‑text SSN column has been removed.\n- Enable the PostgreSQL `pgcrypto` extension with the script `scripts/enable_pgcrypto.sql` if you opt for DB‑side encryption in the future.\n
