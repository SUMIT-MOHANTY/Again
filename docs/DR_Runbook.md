# Disaster Recovery Run‑book\n\n## 1. Required environment variables\n- `BACKUP_DIR` - Directory where `.sql` dump files are stored (default `./backups`).\n- `POSTGRES_URI` - PostgreSQL connection string, e.g. `postgresql://user:pass@localhost:5432/yourdb`.\n\nThese can be placed in `config/.env` (or exported in the shell).\n\n## 2. Running the scripts manually\n```bash\n# Make scripts executable (once)\nchmod +x scripts/*.sh\n\n# 1) Perform a backup now\n./scripts/backup_postgres.sh\n\n# 2) Verify the most recent backup can be restored\n./scripts/verify_restore.sh\n\n# 3) Clean up old backups, keeping the latest 7\n./scripts/cleanup_backups.sh\n```\n\n## 3. Recovery steps (restore from a chosen backup)\n1. Identify the backup file you wish to restore, e.g. `backups/backup_20230301_020000.sql`.\n2. Drop the target database (or create a new one) using `psql`.\n   ```bash\n   psql "$POSTGRES_URI" -c "DROP DATABASE IF EXISTS mydb;"\n   psql "$POSTGRES_URI" -c "CREATE DATABASE mydb;"\n   ```\n3. Restore the dump into the target database:\n   ```bash\n   pg_restore -d "mydb" path/to/your/backup.sql\n   ```\n4. Verify the restore by connecting and running a simple query:\n   ```bash\n   psql "mydb" -c "SELECT count(*) FROM information_schema.tables;"\n   ```\n## 4.
